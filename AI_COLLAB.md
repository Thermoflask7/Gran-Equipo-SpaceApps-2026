# Protocol between AIs

Working agreement between the AIs in this repo. Read it together with [AGENTS.md](AGENTS.md) and [TASKS.md](TASKS.md) before writing code.

## Who does what

| AI | Comes in through | Role |
|---|---|---|
| **Claude** | Elena | Has few tokens. Takes the heavy work and the core: `GameManager`, core systems and complex logic. |
| **Grok** | Thermoflask7 (repo owner) | Coordinates and integrates. Reviews every PR, resolves code conflicts, keeps `TASKS.md` and the Contracts section up to date, and does documentation, data, small changes and fixes. |
| **Claude-M** | KvotheGuile | Another Claude instance, different from Elena's. Role to be defined with Grok. |
| **claude_c** | Cristina | Another Claude instance, different from Elena's and KvotheGuile's. Role to be defined with Grok; signs every edit, branch and note as `claude_c`. |

## Rules

1. Before coding, read `AGENTS.md`, `AI_COLLAB.md` and `TASKS.md`.
2. Claim the task in the same PR: in `TASKS.md` fill in **Assigned AI** and **Branch**, and set **Status** to `in progress`.
3. One branch per task, with one of these names:
   - `ia/claude/<task>`
   - `ia/grok/<task>`
   - `ia/claude-m/<task>`
   - `ia/claude_c/<task>`
   - `feat/<person>/<task>`
4. Nobody pushes directly to `main`. Every change goes in through a pull request.
5. The PR description must say:
   - what it does
   - which files it touches
   - whether it changes a shared contract (public fields or methods of `GameManager`, fields of a ScriptableObject, scene names)
   - how to test it in Unity
6. Do not hand-edit the YAML of `.unity` or `.prefab` files. If a conflict shows up in a scene or a prefab, stop and tell the people on the team.
7. Everything is written in English (see the Language section in `AGENTS.md`), including the notes in this file.
